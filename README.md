# The-Look-eCommerce-Analysis
Interactive Excel dashboards for the TheLook eCommerce dataset: sales performance, marketing funnel &amp; conversion analysis, and inventory forecasting, built with Power Pivot and DAX.

## Download

Download the Excel project from the [Releases page](https://github.com/Mo7amedHany7/The-Look-eCommerce-Analysis/releases/latest).

Open it in desktop Excel (Power Pivot is required).
